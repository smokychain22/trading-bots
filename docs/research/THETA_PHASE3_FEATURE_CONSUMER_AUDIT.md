## Source anchors and empirical boundaries

- `src/theta/theta-shadow-cycle.ts`: acquisition, normalization, timestamps,
  feature attachment, candidate-specific inputs and archival handoff.
- `bots/theta/quant/models/ownership_v0.py`: liquidity, structural, recovery,
  tail and event components. Return fields are accepted but not scored.
- `bots/theta/quant/models/regime_v0.py`: RV20, slope, gap, event/liquidity and
  drawdown classifications. Missing fields remain explicit.
- `src/theta/account-exposure.ts`: sole-risk-group bound. The separate held-symbol
  correlation observation does not silently supply cluster membership.
- `src/research/shadow-feature-contribution.ts`: only disclosed VRP bootstrap
  weight is nonzero. Repeated feature IDs fail, rather than double weight.
- `src/theta/phase2-market-intelligence-registry.ts`: five-strategy six-role
  projection. It is governance metadata, not an independent runtime ranker.

Ownership's multiplicative structural formula is explicitly versioned and
unproven. The overlap and usefulness of trend/tail/event components require
resolved outcomes and controlled ablation. That is an empirical limitation,
not evidence that the software has learned profitable weights.

Current policy permits only Q for Paper-facing new risk. H/D comparisons and
their required inputs retain shadow authority. Recovery/CC evidence is
action-specific, with passive holding distinct from quote-dependent actions.
No additional feature has been promoted by this review.
