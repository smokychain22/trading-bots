# Minimal prospective THETA evidence producer specification

Status: research specification only. Not implemented, deployed, scheduled or authorized to place orders. Reuse existing THETA contracts and storage under a separately reviewed scope; do not create a second strategy engine, broker adapter, database or trading account.

## Narrow first outcome
Produce one complete, sealed **Paper-shadow opportunity path**, including rejected alternatives and a censored terminal state if necessary, from existing authorized session observations. Use one predeclared symbol from the existing collector’s currently entitled universe. A path validates evidence plumbing, not strategy performance. No new paid OPRA, account, secrets, or entitlement expansion.

This is a source-interface research recommendation, not a runtime inspection. Before implementation, pin current source SHA, inspect canonical types, and map these requirements into them. Prior names such as `ObservationBundle`, `validateDotProposal`, `evaluateDotShadowProposal` for H/D, and `evaluateDotCanonicalProposal` for Q/A/C identify existing integration seams. They are not a claim that a current deployed runtime supports all required fields. Existing sealed T0/bundle hashes, domain replay and fail-closed admission must remain the authority.

## Minimum append-only record groups
1. **Receipt and rights:** evidence ID, immutable content hash, source/feed, actual entitlement, permitted storage/use/retention, collection timestamp UTC, source event timestamp, first receipt timestamp, decision-visible availableAt, validUntil, local exchange session and calendar version. Preserve source endpoint/request identity without credentials. Version corrections separately; never overwrite first-known data. Unknown clocks block causal admission.
2. **Contract:** OCC symbol plus source contract ID, expiry date and settlement convention, put/call, strike, known multiplier and deliverables, standard/adjusted flag, corporate-action reference. Validate encoded expiry against displayed expiry and computed calendar DTE. Preserve calendar DTE and remaining tradable sessions separately. Unknown/nonstandard deliverables reject entry qualification.
3. **Quote:** bid/ask, both sizes, bid/ask event times where supplied, quote time/receipt, venue/consolidation authority, condition flags, indicative/delayed/model-derived status. Preserve last trade separately. Crossed, stale, one-sided, zero-size, missing or session-invalid observations are reason-coded, not converted to zero prices or fills. A Paper indicative reference never becomes live NBBO.
4. **Underlying and features:** raw stock bar/quote, interval start/end, receipt/first-known revision chain, adjustment status, price/volume and feature calculation window. Every feature dependency must have been available before the decision. IV/Greeks include model/provider/as-of; OI and events include publication clocks, not only the economic event date.
5. **Opportunity and decision:** complete eligible/rejected candidate set, canonical family Q/H/D/A/C (R only management route), baseline version/hash, proposal hash, gates, rejection reasons, rankings and sizes, selected action, missing-input reasons, AEGIS result. Preserve all baseline-eligible 2-DTE H candidates as exclusions; retained 3–5 objects/economics/quantity must be identical. No H roll. Do not implement net-50/net-80 by relabeling gross fixed targets; FIXED_80 is absent.
6. **Lifecycle:** permitted account snapshot binding in private storage; collateral/buying-power reservation, pending orders/fills/cancels, inventory lots/settlement and committed short-call contracts. Shadow decisions do not fabricate broker orders. Capture actual broker lifecycle events only from existing authorized receipts; assignment/stock transfer/dividend/call-away need reconciliation. A/C cannot start from assumed owned or unencumbered stock.
7. **Outcome/cost ledger:** entry economics, contemporaneous feasible close references, fees known/estimated/unknown, spread/slippage sensitivity, risk/time/event exits, failed/partial closes, expiration and terminal stock value, capital-hours, censored reasons. D requires synchronized legs and either real complex-order execution evidence or explicitly conservative scenario bounds; summed mids are not a fill.

## Bounded collection proposal
Use the existing collector's cadence and current authorized feed, without increasing polling rights. At each already-recorded decision seal the input bundle, then append the subsequent management observations through a predefined common horizon. Start with one symbol, one opportunity, and the canonical existing byte/row limits. Preserve a private raw receipt plus a sanitized aggregate research report; publish no account IDs, raw private fills or licensed source payloads. Retention follows provider terms, not an invented unlimited archive.

If current collector lacks first-known timestamps or rights to store/replay source payloads, stop admission and emit DATA_GAP; do not ask OpenAI to supply missing quotes. A reviewed producer change may become the smallest next action, but this document grants no implementation authority.

## Acceptance and falsification
- Clocks: event<=receipt<=decision-visible availability<=decision; bounded negative clock skew only with explicit trusted correction metadata. Missing or impossible ordering blocks admission. AvailableAt is actual visibility, not mechanically equal to period-end.
- Integrity: verify payload hashes and dependency IDs; same T0 input for baseline/challenger; reject mixed snapshots, future-labelled features, overwritten revisions and unknown exposure.
- Contract: symbol expiry and DTE match; actual sessions and holidays recorded; standard deliverables and known multiplier.
- Quotes: feed authority and age qualify under unchanged gates; date-only bars cannot pass option BBO admission. D leg synchronization is checked; stale replacement rejected.
- Coverage: record no-op/rejection/empty-cohort decisions, skipped polls and outage intervals. Never treat no observation as no adverse move.
- Lifecycle: inventory cannot be sold or covered twice; partial fills, assignments and stock losses remain in chain-level economics. Forced exits outrank discretionary holds as specified by canonical policy; missing evidence never becomes a positive EV.
- Censoring: distinguish NO_FILL, NO_CLOSE_REFERENCE, MISSING_TERMINAL, OUTAGE, UNRECONCILED_ASSIGNMENT and RIGHTS_BLOCK. Report each denominator rather than dropping difficult cases.
- Success criterion for producer: one integrity- and clock-qualified complete/censored path and at least one correctly rejected future/stale/mismatched fixture, reviewed against canonical schemas. This is a plumbing criterion, not market validation or permission to trade.

## Study staging after producer review
First validate the exact original Q entry and successive marks. Next collect paired H 2–5 versus 3–5 opportunities without changing exits. Separately study net-exit policies only if the canonical consumer truly supports them. Then compare D at identical short-leg/expiry and common horizon, and A/C only with actual ownership lineage. Require predeclared regimes, cost models, common horizons and independent date-based OOS blocks before any strategy ranking on returns. Sample sufficiency must follow estimated effect precision/tail exposure, not an arbitrary win-rate target.
